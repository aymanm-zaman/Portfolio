Programming Winter 2024

Bike Share Data Analysis

Course APS106 — Fundamentals of Computer Programming
Language Python
Libraries Pandas
Concepts Data wrangling, grouping, filtering

Overview

The dataset consists of quarterly Toronto Bike Share trip records spread across multiple CSV files, each with year and quarter metadata embedded in the filename. The task was to build a pipeline that could load, parse, merge, and analyse this data into clean DataFrames for three analysis tasks.

Implementation

Three functions were implemented: create_bikeshare_df loads all CSVs, parses year and quarter from filenames, and concatenates into a single DataFrame. rank_station_usage filters by year and quarter, counts departures and returns per station, and sorts by total activity. average_trip_duration_by_membership computes mean trip duration separately for Member and Casual users across all year/quarter combinations.

Results

All functions produced correctly structured DataFrames. The station ranking surfaces the busiest locations by combined activity, and the membership analysis shows consistent differences in average trip length between member and casual users across quarters.

def create_bikeshare_df(filenames):
    bike = []
    for file in filenames:
        bike_data = pd.read_csv(file)
        x = file.find('(')
        y = file.find(')')
        bike_data["year"]    = int(file[x + 1 : x + 5])
        bike_data["quarter"] = int(file[y - 1 : y])
        bike.append(bike_data)
    return pd.concat(bike)

def rank_station_usage(df, year, quarter):
    new_df = df[
        (df["year"] == year) &
        (df["quarter"] == quarter)
    ]
    usage["departure_count"] = (
        new_df["from_station_name"].value_counts()
    )
    usage["return_count"] = (
        new_df["to_station_name"].value_counts()
    )
    usage["combined_departure_return_count"] = (
        usage["departure_count"] + usage["return_count"]
    )
    return usage.sort_values(
        by=["combined_departure_return_count"],
        ascending=[False]
    )
