Bike Share Data Analysis

Pandas-based data analysis pipeline for the Toronto Bike Share dataset. Aggregates multi-file CSV trip records, ranks stations by usage volume, and computes average trip duration segmented by membership type and quarter.

Course APS106 — Fundamentals of Computer Programming
Language Python
Libraries Pandas
Concepts Data wrangling, Grouping, Filtering

Overview

The dataset consists of quarterly Toronto Bike Share trip records spread across multiple CSV files, each named with embedded year and quarter metadata. The task was to build a pipeline that could load, parse, merge, and analyse this data — producing clean DataFrames for three distinct analysis tasks.

Implementation

Three functions were implemented:

  • create_bikeshare_df — loads all CSVs, parses year and quarter from each filename using string indexing, appends them as columns, and concatenates into a single unified DataFrame.
  • rank_station_usage — filters by year and quarter, counts departures and returns per station using value_counts(), combines them, and sorts by total activity descending.
  • average_trip_duration_by_membership — iterates over all year/quarter combinations, computes mean trip duration separately for Member and Casual user types, and returns a summary DataFrame.
lab9.py 
def create_bikeshare_df(filenames):
    bike = []
    for file in filenames:
        bike_data = pd.read_csv(file)
        x = file.find('(')
        y = file.find(')')
        bike_data["year"]    = int(file[x + 1 : x + 5])
        bike_data["quarter"] = int(file[y - 1 : y])
        bike.append(bike_data)
    return pd.concat(bike)

def rank_station_usage(df, year, quarter):
    new_df = df[
        (df["year"] == year) &
        (df["quarter"] == quarter)
    ]
    usage["departure_count"] = (
        new_df["from_station_name"].value_counts()
    )
    usage["return_count"] = (
        new_df["to_station_name"].value_counts()
    )
    usage["combined_departure_return_count"] = (
        usage["departure_count"] + usage["return_count"]
    )
    return usage.sort_values(
        by=["combined_departure_return_count"],
        ascending=[False]
    )

Results

All three functions produced correctly structured DataFrames. The station ranking correctly surfaces the busiest locations by combined departure and return volume, while the membership duration analysis shows consistent differences in average trip length between members and casual users across all quarters.
