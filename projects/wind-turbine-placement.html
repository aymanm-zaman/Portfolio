Wind Turbine Placement

Course APS106 — Fundamentals of Computer Programming
Language Python
Libraries csv (stdlib)
Concepts OOP, Geometry, File I/O

Overview

Each wind turbine occupies a circular exclusion zone. Two turbines conflict if their zones overlap. The system reads proposed placements from a CSV file, constructs objects for each turbine, and reports the count of invalid placements.

Implementation

Three classes form a hierarchy: Point represents a 2D coordinate, Circle models a turbine's exclusion zone and implements overlap detection using the Euclidean distance formula, and WindTurbine wraps a Circle with an ID and a list of conflicting neighbours.

Overlap is detected when the distance between two circle centres is less than the sum of their radii. The pairwise check divides the total count by two to avoid double-counting symmetric overlaps.

Results

The system correctly identifies all overlapping turbine pairs from the input data and returns an accurate count of invalid placements.

lab8.py 
class WindTurbine:
    def __init__(self, id_number, x, y, radius):
        self.id_number = id_number
        self.placement = Circle(x, y, radius)
        self.overlapping_turbines = []

    def validate_placement(self, turbines):
        for turbine in turbines:
            if self.id_number != turbine.id_number:
                if self.overlap(turbine):
                    self.overlapping_turbines.append(turbine)

def check_turbine_placements(turbines):
    invalid = 0
    for i in range(len(turbines)):
        for j in range(len(turbines)):
            if i != j and turbines[i].overlap(turbines[j]):
                invalid += 1
    return int(invalid / 2)
